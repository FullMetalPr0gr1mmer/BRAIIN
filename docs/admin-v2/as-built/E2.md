## Plan (written before the build)

Releases are off in production until R14. The preview column adds no write: it frames R9's
preview route, which with releases off renders the live page (no pending change exists), and
with them on lays the role's pending changes over it. Every write the editor sends is E1's,
byte for byte (`tests/lib/releaseModeWrites.spec.ts`, `releaseOffWrites.spec.ts` unchanged).

**Scope (E2 only).**

1. **The column** (`src/components/admin/screens/pagePreview/PreviewColumn.tsx`, loaded through
   `import()` on first need, its own lazy chunk group `admin-page-preview`):
   - an iframe of `/admin/preview<path>` (`toPreviewPath`, R9) for the page's English or Arabic
     address, titled "Live preview of <page>";
   - Desktop / Tablet / Phone (1280 / 834 / 390 px), rendered at that width and scaled to the
     column through the CSSOM after hydration (no `style=`, CSP §3);
   - the language follows the editor's (English, العربية; Both keeps the last one), with its own
     English / العربية switch in the column's bar; a change swaps the frame's address;
   - Reload preview; a note while it loads, and one when the frame answers without the bridge
     (an error page);
   - the bar's words, honest per mode: releases on "Your edits are saved as drafts. Nothing
     changes on the site until you publish." (ui.md); releases off the page as visitors see it,
     each save changing the site and the preview reloading after it.
2. **Following the editor.** On the bridge's `ready` the column sends `jump` and `highlight` for
   the open section; selecting another section sends both again; after each save the editor
   makes (a field save or autosave, the eye, a move, Add section, a removal, the page details, a
   History restore) the column sends `reload` once (debounced, so an autosave burst is one
   reload), then jumps back on the next `ready`. A section the preview does not show (hidden,
   or not on that page) gets a plain note instead of a highlight.
3. **Clicking a section in the preview selects it** (ui.md). The envelope gains one
   preview-to-parent message, `select` (a section id), sent by the bridge for a click inside a
   `data-pv-section` element that is not on a link; the editor takes it only for a row it lists,
   through E1's own `select` (so unsaved work is asked about first).
4. **A link followed inside the preview** (R9 keeps it in the preview and reports `navigate`):
   the column says it shows another page and offers "Back to <page>".
5. **Layout** (ui.md "Responsive"): 1280 px and up, three columns (sections, fields, preview);
   below, an "Edit | Preview" switch shows the fields or the preview beside the sections list
   (E1's departure 12 keeps the list stacked above below 1024 px). The frame is mounted only
   while it is on screen, so a narrow screen that never opens the preview never asks the Worker
   for one (P-15).
6. **Who.** Admin and Content Creator (`pages.write`, the roles that get E1's columns). SEO opens
   the editor's SEO card only (E1), so no preview column. Developer and Sales are refused by the
   editor (E1). The preview route keeps its own gate (R9, `PREVIEW_READ_CAPS`).
7. **The bridge** (P-4): the parent half stays `src/lib/admin/previewChannel.ts` (R9), the
   preview half `src/lib/admin/preview/bridge.ts`; both keep the explicit same-origin
   targetOrigin, the origin AND source checks, and the Zod envelope.
8. **CSP.** No policy change: `/admin/**` already sends `frame-src 'self'` (R9's `frameSelf`),
   every response `frame-ancestors 'self'` and `X-Frame-Options: SAMEORIGIN`, and a preview
   render its own policy (R9: `form-action 'none'`, `connect-src` of `READ_ONLY_ENDPOINTS`).
   The column's sizes are CSSOM writes after hydration.
9. **Bundle.** `admin-page-preview` (the column and the parent channel), reached only through
   `import()` from the editor: `scripts/admin-bundle.mjs` gains it in its lazy-only and
   off-screen lists; `admin-ui` no longer claims `previewChannel.ts`. If the build's admin sum
   crosses the 400 KB tripwire, `.size-limit.json` moves to 450 KB with the CLAUDE.md §2
   amendment the owner decided on 2026-10-28 (the per-screen eager graph ≤ 300 KB stays the
   binding budget).
