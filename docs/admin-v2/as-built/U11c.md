## Plan (written before the build)

**Scope.** Close U11's residual: until now an Admin or SEO token could write anything into
`site_integrations`' four legacy jsonb columns (`ga4`, `search_console`, `calendly`,
`recaptcha`) through PostgREST and read it back. Nothing else changes: no screen, no route, no
guide.

**Revoke or drop.** At 0105's push the NOTICE counted 0 production rows holding legacy JSON,
so the columns hold nothing worth keeping and DROP COLUMN is the clean contract: no residual
grant to reason about, nothing a later grant could reopen. The migration still counts again
at its own push and refuses (raises, so nothing is dropped) if any row holds JSON by then, so
a value written in the window between 0105 and this push is never destroyed unread.

**Migration.**
1. `set local lock_timeout = '5s'`.
2. The precondition: no row holds legacy JSON (else the push stops, with what to do).
3. `alter table public.site_integrations drop column ga4, drop column search_console, drop
   column calendly, drop column recaptcha` (RESTRICT: a dependent object fails the push).
4. Grants restated (P-14): revoke all from PUBLIC, anon, authenticated, service_role, then
   U11's grants on the columns that remain.
5. Postconditions under both grant regimes: the four columns gone and the table's columns
   exactly the seven that remain; RLS ENABLE + FORCE; the exact policy set, tenant first; the
   table and column privileges of every API role, what must and must not hold (TRUNCATE,
   REFERENCES, TRIGGER; MAINTAIN under a version CASE); the three CHECKs; no function in
   `public` or `app` names the table; still out of the release registry.

**Proof the deployed Worker keeps working** (between the push and the deploy). A new unit
spec, `tests/lib/integrationsContract.spec.ts`: the table's columns replayed from every
migration, then every reader's columns held inside them: the admin load and the route
(`INTEGRATION_COLUMNS`, `INTEGRATION_DEFAULTS`, the route's `toRow`), the public loader
(`SEARCH_CONSOLE_COLUMN`), the preview dataset's projection, the editor's fields,
export-backup's table list, the seeds; a source scan that no file naming the table names a
legacy column; no SQL function or view reads the table.

**Tests.** pgTAP `integrations.test.sql` (the legacy write now 42703, the columns and the
staff column grants exact; `plan(n)` recounted), `grants_app_schema.test.sql` (its anon
assertion named `recaptcha`, which no longer exists; one assertion added); the unit spec
above; `integrationsSql.spec.ts`'s residual test turned into "closed, and said so".

**Docs.** CLAUDE.md's U11 bullet, U11.md's residual and owner item, the deviations register's
